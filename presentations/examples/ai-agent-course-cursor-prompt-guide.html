1｜開始前：裝好、登入、開資料夾

  • 安裝 Cursor 桌面版：到 cursor.com/downloads 下載安裝（Mac：macOS 12 以上；Windows：10 以上）。
  • 在電腦上登入 Cursor：打開 Cursor，依畫面登入。如果訂閱是用手機買的，請在上課前先確認電腦登入得進去。
  • 開一個練習資料夾：在桌面新增資料夾（例如 pool-game），然後在 Cursor 選「File → Open Folder」打開它。
  • 打開 Agent 對話框：Mac 按 Cmd+I（Windows 是 Ctrl+I）。之後所有提示詞都貼在這裡。

如果一打開看到的是「Agents Window」，而不是有檔案列表的編輯器：Mac 按 Cmd+Shift+P（Windows 是 Ctrl+Shift+P），輸入「Open IDE」就能切回編輯器。（依 Cursor 官方文件，2026-10-20 查閱）

2｜十個名詞，一句話說完

名詞白話意思
Prompt（提示詞）你打給 AI 的一段話，說清楚要它做什麼。
Agent（代理）Cursor 裡會自己動手的 AI：會讀檔案、寫檔案、跑指令，不只回答問題。
專案資料夾這次作品放在哪一個資料夾。Agent 只在你打開的資料夾裡工作。
HTML 檔網頁檔案，例如 index.html。雙擊就會用瀏覽器打開。
預覽用瀏覽器打開，看看做出來的樣子。
本機／雲端本機：AI 在你這台電腦上做事。雲端（Cloud）：AI 在網路上的另一台電腦做事，你的電腦上看不到它做的檔案。上課一律用本機。
127.0.0.1／localhost代表「這台電腦自己」的網址。網頁如果其實跑在別台電腦上，你用這個網址就打不開。
Diff（變更對照）AI 改了哪些地方：新增的和刪除的內容會用不同顏色標出來。
Checkpoint（還原點）AI 每次大改之前會自動存一份。改壞了可以按「Restore Checkpoint」回到之前的樣子。
驗收你自己點一點、看一看，確認真的做到了。不能只聽 AI 說「完成了」。
Commit（存版本）用 Git 幫作品存一個有名字的版本，方便之後回頭找。選做；電腦要先裝好 Git。

3｜固定流程卡：每次都這樣做

  1. 開資料夾File → Open Folder，確認左邊看得到這個資料夾。
  2. 說目標按 Cmd/Ctrl+I，貼上「開頭提示詞」和這次的五段式提示詞。
  3. 看結果看 AI 說它做了什麼、改了哪些檔案（Diff），再打開網頁看看。
  4. 請它修哪裡不對，就照「修正提示詞」說：看到什麼、應該是什麼。
  5. 驗收照提示詞裡的驗收條件自己點一遍，一項一項打勾。
  6. 存檔／存版本貼上「結尾提示詞」，留一份說明；想存版本再請它 Commit。
開頭提示詞（每次新任務先貼這段）
請先看一下這個資料夾裡有什麼，用三句話告訴我。
接下來的規則：
1. 只在這個資料夾裡工作。
2. 網頁做成可以直接雙擊打開的 index.html，不要用外部套件，不要啟動伺服器，不要部署。
3. 用繁體中文回答我，說明要簡單，我是新手。
4. 不確定的地方先問我，不要自己猜。
修正提示詞（看到問題時）
我打開網頁後看到：【畫面上看到什麼／錯誤訊息全文】
我期待的是：【應該怎樣】
請只修這個問題，其他功能不要動。修好後告訴我怎麼確認。
結尾提示詞（每次做完都貼這段）
請幫我整理這次的成果：
1. 改了哪些檔案
2. 我要怎麼打開來看
3. 我自己驗收要點哪 3 個地方
4. 還有什麼沒做、沒測，或你不確定的地方
最後把以上內容寫進 README.md。
選做：存一個版本（電腦已裝 Git 才用）
請用 Git 幫我存一個版本，說明寫「【這次做了什麼】」。只存這個資料夾，不要上傳到網路。

4｜本機與雲端：最常見的坑

症狀：Cursor 說做好了，但瀏覽器打不開，出現 127.0.0.1 … ERR_CONNECTION_REFUSED

原因：網頁伺服器不在你這台電腦上，例如 Agent 跑在雲端的另一台電腦，或伺服器已經關掉了。127.0.0.1 指的是「你這台電腦」，你的電腦上沒有東西在跑，所以連不上。

怎麼避免：

  • 在 Agent 輸入框下方的選單確認不是 Cloud（雲端）。上課一律用本機。
  • 開頭提示詞已經寫了「做成雙擊就能打開的 index.html、不要啟動伺服器」。這樣不需要任何網址，到資料夾雙擊檔案就能看。
  • 已經卡住時，貼這段給 Agent：
我打不開預覽，瀏覽器顯示 ERR_CONNECTION_REFUSED。請不要用伺服器，改成單一 index.html，存在我打開的這個資料夾裡，並告訴我檔案的完整路徑，我要自己雙擊打開。

6｜撞球遊戲三步做出來

每一步都在同一個資料夾、同一個對話裡接著做。先做完一步、驗收過了，再貼下一步。

第 1 步做出能玩的原型

目標：在這個資料夾做一個可以直接玩的撞球網頁小遊戲，畫面用繁體中文。
功能：
1. 一張球桌、白球、15 顆色球、6 個球袋；球會互相碰撞、碰到桌邊會反彈、會慢慢停下、會進袋。
2. 用滑鼠或手指拖曳來瞄準，畫面上顯示瞄準虛線；用滑桿設定力道，按「擊球」出桿。
3. 白球進袋後，可以把它重新放回桌上的空位。
4. 顯示進球數和桿數，有「重新開始」按鈕。
限制：只做一個 index.html，不用外部套件，雙擊就能打開；不要啟動伺服器，不要部署。
驗收：告訴我怎麼測下面三件事。
交付：告訴我檔案在哪裡、怎麼打開。
  • 改角度和力道之後，白球的方向和距離跟著變。
  • 球還在滾的時候按「擊球」，桿數不會增加。
  • 白球進袋後可以放回桌上；「重新開始」可以用。手機打開也能用手指瞄準。

第 2 步加上自動打和設定

目標：在剛剛的撞球遊戲加上「自動打」和設定，原本的手動玩法要保留。
功能：
1. 按「自動打」後，電腦自己選一顆球：先顯示瞄準虛線、力道和球桿後拉的動作 2.5 秒，再出桿；等所有球停下，再打下一桿。
2. 按「暫停」後就不再出桿（已經在滾的球讓它滾完）。
3. 設定區：瞄準秒數（2–3 秒）、球滾動速度、力道上限；重新打開網頁後，設定還在。
4. 找不到能進的球時，畫面上說明原因，不要假裝一定會進。
限制：只改 index.html；不要改掉原本的手動玩法和畫面風格。
驗收：告訴我怎麼測下面三件事。
交付：列出這次改了什麼。
  • 自動打時，看得到約 2.5 秒的瞄準動作，之後才出桿。
  • 按「暫停」之後，不會再自動出桿。
  • 重新整理網頁後，設定還在。

第 3 步加上聲音和音量

目標：讓撞球遊戲有聲音，而且可以調音量。
功能：
1. 球桿打到白球、球碰球、球進袋，各有一種聲音；不用下載音效檔，用瀏覽器內建的方式產生聲音。
2. 打得越用力、撞得越快，聲音越大；球靜止靠在一起時不要一直響。
3. 音量滑桿 0–100%，預設 70%，0% 就是靜音；重新打開網頁後音量還在。
限制：手動和自動玩法都要保留；只改 index.html。
驗收：告訴我怎麼測下面三件事；你沒有真的聽過的部分，請老實說。
交付：列出這次改了什麼。
  • 手動打一桿，聽得到擊球、球碰球、進袋三種聲音（瀏覽器規定要先點一下畫面才會出聲）。
  • 音量拉到 0%，完全沒有聲音。
  • 自動打的時候也有聲音；重新整理後，音量設定還在。

7｜模糊說法 → 清楚說法

模糊說法清楚說法
幫我優化這次只改一件事：【哪一件】；改完我要看到【什麼】
做一個撞球遊戲列出功能：瞄準虛線、力道滑桿、會進袋、重新開始
每 2–3 秒打一次瞄準畫面停 2.5 秒才出桿；等球都停下，再算下一桿
要有聲音哪三種聲音、音量 0–100%、0% 是靜音、重開後設定還在
想好再出桿先算完再開始瞄準動畫；算的時候畫面顯示「計算中」
做好給大家看先做本機版；要公開分享，另外說放哪個網站、誰能看
測試都要過列出 3 個我要自己點的檢查；沒測的要說沒測

8｜交出去前的檢查清單

  • Agent 是本機，不是 Cloud；檔案在我打開的資料夾裡看得到。
  • 提示詞有寫目標、功能、限制、驗收、交付五段。
  • 我自己打開網頁點過，驗收條件一項一項打勾。
  • 手機（或把瀏覽器拉窄）也能看，不用左右捲動。
  • 原本已經會的功能，改完之後還是會。
  • AI 說「沒測」或「不確定」的地方，我有記下來。
  • 已經貼過結尾提示詞，README.md 有說明怎麼打開。
  • 沒有放真實客戶資料、密碼或公司機密。
卡住三步：① 截圖（整個畫面，包含錯誤訊息）② 傳到 LINE 群組，寫「卡住＋第幾步」③ 先把同一張截圖貼給 Agent，問「這是什麼意思、我下一步要按哪裡」。

9｜找自己的專題：AI 專題教練

先想清楚「誰，卡在哪一步」，再決定要做什麼。題目可以從四個地方找：

來源例子
工作上的問題報價流程
專業介紹你的產品或服務幫客戶、同事解決什麼，例如優化公司官網的服務表單
興趣、社團、協會撞球遊戲、棋品空間-棋藝交流中心
資訊系統旅遊行程、設備管理、報價、記帳

四步：① 選一個真實情境 ② 寫成一句話「誰，想要完成什麼，現在怎麼做」 ③ 列 5–7 個步驟，圈出最痛的 1–2 步（最花時間、最常出錯、最常等人） ④ 第一版只解決那一步，3–5 個畫面。

好題目三標準：有人真的會用、一句話講得清楚、第一版 3–5 個畫面。太大就縮，例如「設備管理」→「設備借還登記」。撞球適合熱身或興趣題；第 8 週成果發表，請選有明確使用者和痛點的題目。

AI 專題教練提示詞（貼到 Cursor 的 Agent 對話）
你是我的 AI 專題教練。請一次只問我一個問題，引導我找出這次 AI 課程的專題，不要一次問完。只用對話，先不要建立或修改任何檔案。
題目可以來自：1. 工作上的問題（如報價流程）2. 我的產品或服務幫客戶、同事解決什麼（如優化官網服務表單）3. 興趣、社團、協會（如撞球遊戲、棋品空間-棋藝交流中心）4. 資訊系統（如旅遊行程、設備管理、報價、記帳）。
引導步驟：A. 選一個情境，寫成一句話「誰，想要完成什麼，現在怎麼做」 B. 列出 5–7 個步驟 C. 圈出最痛的 1–2 步（最花時間、最常出錯、最常等人） D. 第一版只解決那一步，最多 3–5 個畫面。題目太大請幫我縮小。
最後用這個格式整理：專題名稱／使用者是誰／任務一句話／目前步驟／最痛的步驟與原因／第一版要做的功能（最多 3 項）／需要哪些畫面／怎麼算成功。

教練整理出來的格式，就是第 2 週作業「一頁專題提案」的內容。

10｜進階（選讀）：會做三步之後

兩桿做球：讓自動打「先想好下一桿再出桿」。重點是把「想好」寫成可以檢查的條件，不是讓它停幾秒。

目標：把自動打升級成「這一桿打完後，下一桿也要好打」。
功能：
1. 出桿前，先模擬這一桿打完後所有球停在哪裡，再模擬下一桿能不能把指定的球打進指定的球袋。
2. 計算時畫面顯示「計算中」，算完才開始 2.5 秒瞄準動畫；計算期間不出桿。
3. 畫面上標出預計的白球停點，以及下一桿要打的球和球袋。
4. 按暫停或重新開始後，舊的計算結果不能再出桿。
限制：保留手動、自動、音效和設定；只改 index.html。
驗收：實際停點和預計停點大致一致；計算期間桿數不增加。沒有驗證過的不要寫成已通過。
交付：列出改了什麼、測了哪些局面、還有什麼限制。

公開分享：要讓別人用網址打開，就要放上網站，例如撞球遊戲範例網站。提示詞要另外寫清楚：放在哪個網站、誰能看、不能讓別人修改。「部署成功」不等於「任何人都打得開」，要用無痕視窗自己試一次。127.0.0.1 不能拿來分享給別人。
