00 / 名詞小卡

今天會一直聽到的 6 個詞

Prompt（提示詞）

你打給 AI 的一段話，說清楚要它做什麼。

Agent（代理）

Cursor 裡會自己動手的 AI：會讀檔、寫檔、跑指令。

專案資料夾

作品放的地方；Agent 只在你打開的資料夾裡工作。

預覽

用瀏覽器打開 index.html，看看做出來的樣子。

本機／雲端

本機＝在你這台電腦做；雲端＝在別台電腦做。上課用本機。

Diff／Checkpoint

Diff＝AI 改了哪裡；Checkpoint＝改壞了可以還原的存檔點。

完整 11 個名詞在《Cursor Prompt 入門教學》第 2 節（右上角連結）。

00 / 開頭與結尾提示詞

每次都用：開頭一段、結尾一段

開頭
開頭提示詞（新任務先貼）

請先看一下這個資料夾裡有什麼，用三句話告訴我。規則：1. 只在這個資料夾裡工作。2. 網頁做成可以直接雙擊打開的 index.html，不用外部套件、不啟動伺服器、不部署。3. 用繁體中文、簡單說明，我是新手。4. 不確定的先問我。

結尾提示詞（做完都貼）

00 / 本機與雲端 · 8′

「Cursor 說好了，網頁卻打不開」：多半是跑到雲端了

為什麼
症狀與原因
  • 瀏覽器顯示 127.0.0.1 … ERR_CONNECTION_REFUSED
  • 127.0.0.1＝「你這台電腦」
  • 網頁伺服器其實在雲端的另一台電腦，或已經關掉
  • 所以你的電腦連不上
怎麼做
怎麼避免
  • Agent 輸入框下方的選單：不要選 Cloud
  • 請它做成單一 index.html，不啟動伺服器
  • 到資料夾雙擊 index.html 打開
  • 已經卡住：貼講義第 4 節的救援提示詞
W1 有線上同學真的遇過：不是電腦壞了，改用本機、雙擊打開就好。
