05 / 痛點① · 跨公司預售產銷

不同公司通路的預售／代售，也要預估產量

現象
  • 他牌／加盟／代售門市（如 G9976、10201 等）有預售或對照銷量
  • POS 品號≠FYH 生產品號，需 cross_company_product_maps
  • SD／購物車預購可能落在「非自營」公司主體
  • 三總等品名後綴要映射回正式常溫品（如 C41→C01）
分析／營運風險
  • 漏估：工廠少做 → 他牌／預售缺貨
  • 重複估：自營＋他牌雙計 → 回存上升
  • 矩陣有欄、主預估卻過濾 → 「看得到賣不到數」
  • qty_factor／對照未啟用 → 靜默(silently)漏量
成功指標草稿：跨公司對照覆蓋率 ≥ 95%；跨公司需求併入主預估誤差 ≤ ±10%；未對照 SKU 告警數每日可清零。

06 / 痛點② · 新品／停售矩陣

生產矩陣必須隨商品生命週期調整

1
主檔異動

新品上架／停售下架、分類、每包粒數

2
矩陣欄位

baseline／avg_sales／回存／天氣敏感度列

3
冷啟動

新品無 31 天同星期歷史 → 需種子或人工覆寫

4
停售殘留

舊列未剔除 → 工廠仍排產／分貨

資料治理要點
  • is_active 與生產分類清單同步
  • 新品：種子基準、類似品代理、或強制 manual_override
  • 停售：自 production_plan／矩陣排除並稽核
成功指標草稿
  • 主檔→矩陣同步延遲 ≤ 1 營業日
  • 停售 SKU 誤入預估列 = 0
  • 新品上線首 7 日人工覆寫率由高→降到 ≤ 30%

07 / 3. 現況做法與成本

ass多源拼圖，兩痛點放大成本

做法
  • 同步 Dudoo／Sheets／SD／天氣
  • 日均基準＋回存＋天氣矩陣＋覆寫
  • 爐盤計算 → Sheets 出貨（人工斷點）
  • 他牌：對照表＋特殊分母規則（草稿）
  • 新品／停售：多半靠人工改主檔與覆寫
成本（含草稿）
  • 計畫人員每日約 45–90 分鐘
  • 跨公司對帳、新品種子額外耗時
  • 估多→回存／報廢；估少→提早完售
  • 系統有回測 MAPE，但生命週期治理仍弱

10 / 6. 決策動作與人工點

系統半自動，兩痛點仍偏人工

系統可做
  • 排程同步、異常單排除（如 >3× 且 >20 包）
  • 一鍵算 baseline／天氣／SD
  • 包→粒→爐盤／BOM；回測 MAPE
  • 對照表啟用後換算他牌量（qty×factor）
人工必須碰
  • 按下產生、倍率、公休特案
  • 維護跨公司對照與預售口徑
  • 新品種子／停售剔除與稽核
  • 計畫寫進出貨 Sheets（最大斷點）

11 / 7. 風險與不能做的事

資料正確性紅線

不能
  • 混加試算表／Dudoo／發票當唯一業績
  • 未排除公休／團購就當長期基準
  • 把建議產量當財務庫存／總帳
  • 略過 RBAC 裸寫生產／主檔
  • 未對照就把他牌銷量硬併進 FYH 產線
  • 停售品仍留在生產矩陣卻不告警
風險
  • 天氣格 n 不足 → F_W 不穩
  • 出貨人工斷點 → 預估準、現場仍錯
  • 過度追低 MAPE → 系統性估多
  • 跨公司雙計／漏計 → 產銷失真
  • 新品冷啟動亂覆寫 → 無法回測歸因
