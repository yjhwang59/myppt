03-1 / 名詞小卡

兩個新詞：GitHub、repo

1
GitHub

一個放專案的網站。檔案存在上面，換一台電腦也能下載回來。今天稍後才會申請帳號，現在先認得這個名字。

2
repo

repository 的簡稱，就是「一個專案資料夾」。你桌上的 cursor-w3 是一個資料夾；放到 GitHub 上，這一個資料夾就叫一個 repo。

存
commit（存一個版本）

03-1 / 開頭與結尾提示詞

跟第 2 週一樣：開頭一段、結尾一段

開頭
開頭提示詞（新任務先貼）

請先看一下這個資料夾裡有什麼，用三句話告訴我。規則：1. 只在這個資料夾裡工作。2. 網頁做成可以直接雙擊打開的 index.html，不用外部套件、不啟動伺服器、不部署。3. 用繁體中文、簡單說明，我是新手。4. 不確定的先問我。

結尾
結尾提示詞（做完都貼）

請整理這次的成果：1. 改了哪些檔案 2. 我要怎麼打開來看 3. 我自己驗收要點哪 3 個地方 4. 還有什麼沒做、沒測或不確定。最後把以上內容寫進 README.md。

帳號
第一次：註冊
  • 瀏覽器打開 github.com

  • 填 Email、密碼、使用者名稱
  • 到信箱點驗證連結

repo

  • 名稱打 my-ai-profile

  • 按 Create repository
  • 成功：看得到 README.md

加碼 / 卡住怎麼辦

三種常見狀況，還有一定要守的安全線

1
授權視窗跳不出來
  • 看工作列有沒有被擋住的瀏覽器
  • Cursor 左下角找 Sign in
  • 還是不行：先做 README，下課再請助教
2
不小心選成 Public
  • 打開該專案的 Settings
  • 拉到最下面 Danger Zone
  • Change repository visibility
  • 改成 private。成功：名稱旁寫 Private
3
不要放上去的東西
  • 密碼、身分證
  • 客戶個資、電話名單
  • 公司報價與機密
  • 不確定就不要貼
安全：個人檔案和課程專題都選 Private。GitHub 做不完不影響今天的必做：首版頁面、修正清單、README 裡的個人檔案。
